Vib-Ribbon VR on a Meta Quest 3 (standalone, no PC needed to play)
https://github.com/CorrieDivitt/Vib-Ribbon-VR

The game is an APK you install on the headset yourself ("sideloading"). It contains no
part of the game: it plays your own copy of the PAL disc (SCES-02873), from a disc
image (a .cue file with its .bin files) that you copy onto the headset once.

WHAT YOU NEED
- Developer Mode on the headset: in the Meta Horizon app on your phone, Devices >
  your headset > Headset settings > Developer Mode (you may be asked to make a free
  developer account first). Restart the headset.
- A USB-C cable, and adb on a Windows PC: Google's "SDK Platform-Tools" for Windows
  (unzip anywhere; the commands below are run in that folder in PowerShell).
- The APK (Vib-Ribbon-VR-Quest-1.0.0.apk, beside this file) and your disc image's folder.

THE EASY WAY: SIDEQUEST
SideQuest (sidequestvr.com, free, for Windows, Mac and Linux) installs APKs on the
headset without typing commands: with Developer Mode on and the headset plugged in,
drag the APK onto SideQuest's window. Its file browser can also copy your disc image
into the headset's Android/data/io.github.corriedivitt.vibribbonvr/files/disc folder
(start the game once first, as in step 3 below). If the game then says it cannot find
or read the disc, do steps 3 and 4 below: the chmod line there lets the game read
files copied in from a PC.

If you would rather do it directly, without SideQuest, follow the steps below.

ONCE
1. Plug the headset in, put it on and allow USB debugging ("Always allow"). Then:
     .\adb devices
   The headset should be listed as "device".
2. Install the game:
     .\adb install -r "C:\path\to\Vib-Ribbon-VR-Quest-1.0.0.apk"
3. Start it once and stop it, so that it makes its own folder (a folder made by adb
   first would belong to adb, and the game could not read it):
     .\adb shell am start -n io.github.corriedivitt.vibribbonvr/org.libsdl.app.SDLActivity
     Start-Sleep 5
     .\adb shell am force-stop io.github.corriedivitt.vibribbonvr
4. Copy your disc image (the folder with the .cue and .bin files) and let the game read it:
     .\adb shell mkdir -p /sdcard/Android/data/io.github.corriedivitt.vibribbonvr/files/disc
     .\adb push "C:\path\to\your disc folder\." /sdcard/Android/data/io.github.corriedivitt.vibribbonvr/files/disc/
     .\adb shell chmod -R a+rwX /sdcard/Android/data/io.github.corriedivitt.vibribbonvr/files
   (The chmod line matters: files copied by adb belong to adb until it runs.)

PLAYING
In the headset: Library, then "Unknown sources" in its list of filters, then Vib-Ribbon VR.
- Touch controllers: Block LT, Loop RT, Pit left grip / X / Y, Wave right grip / A / B.
  The menu button opens the options menu (in a song it pauses). Left stick: go round
  Vibri. Right stick: zoom; flicked sideways: scroll speed. Right stick click: recenter.
  In the menus the left stick moves, RT or A chooses, LT or B goes back.
- Exit is on the title's menu (B jumps to it).
- An Xbox or other Bluetooth gamepad paired with the headset works too.

YOUR OWN MUSIC
Put MP3 or FLAC files in the headset's Music folder: plug it into the PC, allow file
access in the headset, and copy them in Windows' Explorer (Quest 3 > Internal shared
storage > Music; folders inside it are fine). The first time you open the music picker
in the game, the headset asks whether the game may read your music: allow it.
(Without that permission, or with adb, the game's own folder works too:
     .\adb push "C:\path\to\music\." /sdcard/Android/data/io.github.corriedivitt.vibribbonvr/files/music/
     .\adb shell chmod -R a+rwX /sdcard/Android/data/io.github.corriedivitt.vibribbonvr/files )

IF THE DISC IS MISSING
With no disc image on the headset, the game opens a flat window that says so and where
the files go, instead of starting in the headset. Copy the files (steps 3 and 4) and
start the game again.

UPDATING
Install the new APK with step 2 again; your disc, music and save stay. (A test build
from before 1.0 was signed differently: uninstall it first, which deletes the game's
folder, then do steps 2 to 4 again.)

SAVE FILE AND LOG (for problem reports)
     .\adb pull /sdcard/Android/data/io.github.corriedivitt.vibribbonvr/files/save.txt
     .\adb logcat -d -s vibplay:* > quest-log.txt

THIRD_PARTY_NOTICES.txt (inside the APK and beside this file) lists the libraries the
game is built from and their licences.
